# Mascotes das equipes

Os logos e a lista de equipes ficam fora do git (ver `.gitignore`); o app funciona sem eles.

Para mostrar um mascote:
1. Salve a imagem como `palavra.jpg` aqui (quadrada, ~256 px). A palavra vem do nome da equipe, em minúsculas e sem acento.
2. Inclua a palavra em `lista.js`: `window.MASCOTS_LIST = ["palavra", ...];`

Qualquer equipe cujo nome contenha a palavra ganha a imagem.
